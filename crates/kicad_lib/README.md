# cuprite_wire_kicad_lib

Reads KiCad symbol and footprint libraries and SPICE model libraries for
[cuprite_wire](https://crates.io/crates/cuprite_wire).

This crate is an implementation detail of the `kicad_part!` and `spice_part!` macros of
`cuprite_wire` and is published only because they depend on it. Its API may change in any release
without notice; use `cuprite_wire` instead.
